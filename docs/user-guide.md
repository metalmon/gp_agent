# User Guide

## Getting Started

### Installation

1. **Prerequisites**
   - Frappe Bench environment
   - Python 3.10+
   - Node.js 16+

2. **Installation Steps**
   ```bash
   # Navigate to your bench directory
   cd $PATH_TO_YOUR_BENCH
   
   # Get the app
   bench get-app gp_agent --branch develop
   
   # Install the app
   bench install-app gp_agent
   ```

3. **Configuration**
   - Set up your API keys (if required)
   - Configure user permissions
   - Set up integration settings
