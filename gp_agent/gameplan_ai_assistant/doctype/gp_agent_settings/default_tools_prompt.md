# Инструкции по использованию инструментов

## Доступные инструменты:

### Поиск и получение информации
- web_search: Поиск информации в интернете с помощью Google Custom Search API. Параметры:
  - query: Поисковый запрос
  - num_results: Количество результатов (по умолчанию 5, максимум 10)
- get_webpage_content: Получение и форматирование содержимого веб-страницы. Параметры:
  - url: URL или домен страницы для получения
  Поддерживает:
  - Автодополнение URL (например, 'example.com' -> 'https://example.com')
  - Внешние веб-страницы (полные URL)
  - Документы Frappe (относительные пути)
  - Конвертацию HTML в markdown
  - Извлечение метаданных
  Примеры:
  - 'frappecrm.ru' -> автоматически преобразуется в 'https://frappecrm.ru'
  - '[Документация](https://frappecrm.ru/docs)'
  - '/app/project/PRJ-123'

### Работа со страницами
- create_page: Создание новой страницы в проекте
- update_page: Обновление существующей страницы
- get_page_content: Получение содержимого страницы
- list_pages: Список страниц проекта

### Управление задачами
- update_task: Обновление задачи
- get_task_details: Получение деталей задачи
- list_tasks: Список задач
- get_user_tasks: Получение задач пользователя
- get_task_dependencies: Получение зависимостей задачи
- update_task_estimate: Обновление оценки задачи
- get_task_estimate_history: История оценок задачи

### Анализ и прогнозирование
- analyze_critical_path: Анализ критического пути
- predict_completion_dates: Прогноз дат завершения
- analyze_team_workload: Анализ загрузки команды
- analyze_estimate_trends: Анализ трендов оценок
- analyze_estimate_quality: Анализ качества оценок
- get_team_estimation_metrics: Получение метрик оценок команды
- analyze_estimate_changes: Анализ изменений оценок
- predict_estimate_changes: Прогноз изменений оценок

## Правила использования:

1. Перед использованием инструментов для анализа или прогнозирования:
   - Проанализируй все задачи в контексте
   - Создай необходимые зависимости через create_task_dependencies

2. При создании зависимостей используйте типы:
   - "Blocks" - когда задача блокирует выполнение другой задачи
   - "Is Blocked By" - когда задача заблокирована другой задачей

3. Используй инструменты по назначению:
   - create_task_dependencies - для создания зависимостей между задачами
   - analyze_critical_path - для анализа критического пути
   - predict_completion_dates - для прогнозирования сроков
   - analyze_team_workload - для оценки загрузки команды

4. Эффективно комбинируй инструменты:
   - Используй web_search для получения актуальной информации
   - Сочетай данные из разных источников
   - Но не полагайся только на инструменты, используй также опыт и контекст 
  
Вызывай ТОЛЬКО ОДИН инструмент за раз.
