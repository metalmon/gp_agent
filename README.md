## 🌟 Overview

Edwin is an AI-powered project assistant built on the Frappe Framework, designed to enhance project management and decision-making processes. Inspired by behavioral economics insights, including Kahneman's work on decision-making, Edwin aims to provide both practical project management support and intelligent decision guidance.

## 🚀 Quick Start

### Prerequisites

- Frappe Bench environment
- Python 3.10+
- Node.js 16+

### Installation

1. Navigate to your bench directory:
```bash
cd $PATH_TO_YOUR_BENCH
```

2. Get the app from the repository:
```bash
bench get-app gp_agent --branch develop
```

3. Install the app:
```bash
bench install-app gp_agent
```

4. Build and start the development server:
```bash
bench start
```

## 🛠 Development Setup

1. Install pre-commit hooks for code quality:

cd apps/gp_agent
